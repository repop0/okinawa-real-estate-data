# 沖縄 不動産売り出しデータ（niffee）

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23236189.svg)](https://doi.org/10.5281/zenodo.23236189)

沖縄県内で売りに出ている不動産（中古マンション・中古戸建て・土地など）の、**売り出し価格の統計**です。
同じ物件の重複する掲載を1件にまとめてから集計しています。毎月更新します。

- サイト: https://niffee.yourspacelab.com
- 方法論: https://niffee.yourspacelab.com/methodology
- 市町村別の相場: https://niffee.yourspacelab.com/areas

## ファイル

| ファイル | 中身 | 更新 |
|---|---|---|
| `price-index.csv` | **沖縄 売り出し価格指数**。種別ごとの㎡単価の中央値と、基準日（2026-08-08）を100とした指数 | 毎月 |
| `cities/<日付>.csv` | その日の市町村×種別の統計（売り出し中の件数・新着の件数・売り出し価格と㎡単価の中央値・価格の分かる件数） | 毎月1回の時点の値を積み上げる |
| `cities/latest.csv` | いちばん新しい市町村×種別の統計 | 毎月 |

### 列

`price-index.csv`

| 列 | 意味 |
|---|---|
| `observed_on` | 観測日 |
| `property_type` | 種別（`house` 戸建て / `mansion` マンション / `land` 土地 / `invest` 投資物件 / `commercial` 事業用 / `other` その他） |
| `index_base_2026_08_08` | 2026-08-08 を100とした指数 |
| `median_unit_price_yen_per_sqm` | ㎡単価の中央値（円） |
| `n` | 標本の件数 |

`cities/*.csv`

| 列 | 意味 |
|---|---|
| `observed_on` | 観測日 |
| `city_code` | 市町村コード（総務省の全国地方公共団体コードの先頭5桁） |
| `property_type` | 種別（`all` は全種別の合計） |
| `active_n` | 売り出し中の件数 |
| `new_n` | その日の新着の件数 |
| `median_price` | 売り出し価格の中央値（円）。標本が少ない組み合わせは空欄 |
| `median_unit_price` | ㎡単価の中央値（円） |
| `n_priced` | 価格の分かる件数 |
